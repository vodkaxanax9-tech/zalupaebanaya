# Railway Troubleshooting Guide

## Если бот не работает после деплоя на Railway

### 1. Проверьте логи в Railway

1. Откройте ваш проект в Railway
2. Перейдите в раздел "Logs" (или "Deployments")
3. Посмотрите последние логи на наличие ошибок

### 2. Проверьте переменные окружения

1. В Railway перейдите в "Settings" → "Variables"
2. Убедитесь что переменная `BOT_TOKEN` существует
3. Значение должно быть: `8770957416:AAHSjDJ42QfsA5ofKR1T6gzj-Q3ARGK940o`
4. После изменения переменных нажмите "Redeploy" для перезапуска

### 3. Общие проблемы и решения

#### Ошибка: "BOT_TOKEN не найден в переменных окружения"
**Решение:** Добавьте переменную окружения `BOT_TOKEN` в настройках Railway

#### Ошибка: "Invalid token"
**Решение:** Проверьте что токен правильный и не содержит лишних пробелов

#### Бот запускается но не отвечает
**Решение:**
- Проверьте что бот не заблокирован Telegram
- Попробуйте отправить `/start` боту
- Проверьте логи на наличие ошибок API

#### Ошибки сети при проверке юзернеймов
**Решение:** Это нормально если Railway имеет ограничения на сетевые запросы. Бот продолжит работать.

### 4. Перезапуск бота

Если бот работает неправильно:
1. В Railway нажмите "Redeploy" в разделе deployments
2. Или удалите и пересоздайте проект

### 5. Проверка статуса бота

1. Откройте Telegram
2. Найдите вашего бота по имени
3. Отправьте `/start`
4. Если бот отвечает - всё работает
5. Если нет - проверьте логи в Railway

### 6. Контакты для поддержки

Если ничего не помогает:
- Проверьте статус Railway: https://status.railway.app/
- Посмотрите документацию Railway: https://docs.railway.app/

## Быстрая проверка

После деплоя выполните эти шаги:

1. ✅ Проверьте что deployment успешен (зеленый статус)
2. ✅ Проверьте что `BOT_TOKEN` установлен в Variables
3. ✅ Проверьте логи на отсутствие ошибок
4. ✅ Отправьте `/start` боту в Telegram
5. ✅ Попробуйте проверить юзернейм: `testbot`

## Локальное тестирование

Перед деплоем протестируйте локально:

```bash
# Установите переменную окружения
set BOT_TOKEN=8770957416:AAHSjDJ42QfsA5ofKR1T6gzj-Q3ARGK940o

# Запустите бота
python bot.py
```

Если работает локально - проблема в Railway конфигурации.
