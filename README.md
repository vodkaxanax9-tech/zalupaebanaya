# Telegram Username Checker Bot - Railway Deployment

Бот для проверки занятости юзернеймов для БОТОВ в Telegram с автоматической генерацией вариантов.

## Функции

- **Автоматическая генерация вариантов**: из базового имени создает `{имя}bot` и `{имя}_bot`
- **Проверка через Telegram Bot API**: надежный метод без блокировок
- **Красивые отчеты**: моноширинный формат с разделением на свободные/занятые
- **Пакетная проверка**: можно проверять несколько базовых имен сразу
- **Работа 24/7**: деплой на Railway для постоянной работы

## Как работает

Отправляете базовые имена:
```
kow553
puy727
pkla3
```

Бот автоматически проверяет:
- `@kow553bot` и `@kow553_bot`
- `@puy727bot` и `@puy727_bot`
- `@pkla3bot` и `@pkla3_bot`

И возвращает красивый отчет:
```
○ free 2  ● taken 4 · other 0
──────────────

@kow553
○ @kow553bot free
● @kow553_bot taken

──────────────

*свободны*
@kow553bot
@puy727bot
```

## Локальная установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Получите токен бота у [@BotFather](https://t.me/BotFather)

3. Запустите бота:
```bash
python bot.py
```

## Деплой на Railway (24/7)

### Файлы для деплоя уже готовы:

- `bot.py` - основной файл бота
- `requirements.txt` - зависимости Python
- `Procfile` - конфигурация запуска для Railway
- `runtime.txt` - версия Python
- `.gitignore` - исключения для Git
- `.env.example` - пример переменных окружения

### Шаги деплоя:

#### 1. Создайте GitHub репозиторий

1. Зарегистрируйтесь на [GitHub](https://github.com)
2. Создайте новый репозиторий
3. Загрузите все файлы из папки проекта

#### 2. Деплой на Railway

1. Зарегистрируйтесь на [Railway](https://railway.app)
2. Нажмите "New Project" → "Deploy from GitHub repo"
3. Выберите ваш репозиторий
4. Railway автоматически определит Python и создаст проект

#### 3. Настройте переменные окружения

1. В Railway перейдите в настройки проекта
2. Нажмите "Variables" (или "Environment Variables")
3. Добавьте переменную:
   - **Name**: `BOT_TOKEN`
   - **Value**: ваш токен от BotFather

#### 4. Запуск

Railway автоматически запустит бота. Он будет работать 24/7!

## Использование

### В боте:

1. Найдите бота в Telegram и нажмите `/start`
2. Отправляйте базовые имена для проверки:
   - Одно имя: `kow553`
   - Несколько через запятую: `kow553, puy727, pkla3`
   - Несколько через пробел: `kow553 puy727 pkla3`
   - Каждое с новой строки

### Формат имен:

- Должны начинаться с буквы
- Латинские буквы, цифры и подчеркивание
- Длина до 27 символов (чтобы вместить суффикс `_bot`)

## Переменные окружения

- `BOT_TOKEN` - токен вашего Telegram бота (обязательно)

- **Автоматическая генерация**: не нужно вручную добавлять суффиксы
- **Надежная проверка**: использует официальный Telegram Bot API
- **Красивые отчеты**: моноширинный шрифт для удобного копирования
- **Умная обработка**: автоматически удаляет лишние суффиксы

## Troubleshooting

### Бот не отвечает на Railway:
- Проверьте логи в Railway dashboard
- Убедитесь что переменная `BOT_TOKEN` установлена правильно
- Проверьте что бот не заблокирован Telegram

### Ошибки проверки:
- Проверьте интернет-соединение
- Убедитесь что токен бота действительный
- Проверьте лимиты API Telegram
